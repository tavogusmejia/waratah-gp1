Manufacturer links still open

Every item on the GP1-MUR register with no manufacturer page yet. The list works itself out each time you open it — confirm one and it is gone, add an item to the register and it appears. Each one wants the product page — where the item lives now, with its current finishes, options and pricing — not the datasheet. The grey text in each box is a guess, usually just the manufacturer’s own site — it is not filled in: paste the real page over it, or press Use this to take the guess as it stands.

They are grouped by manufacturer, so one open tab does the whole group. Every keystroke is kept in this browser straight away, whatever the database does — and Copy as CSV reads the boxes themselves, so it is complete either way.
